# S&P Suite packages

Public zip host for [S&P Suite](https://github.com/adamjyo/sp-suite-packages). WordPress downloads from here. Do not put private catalog data in this repo.

## Source URL (paste into S&P Suite)

```
https://raw.githubusercontent.com/adamjyo/sp-suite-packages/main/
```

## Files

| File | Plugin |
| --- | --- |
| `suite.json` | Version list S&P Suite reads |
| `SP-Catalog.zip` | S&P Catalog |
| `SP-App.zip` | S&P App |
| `SP-Sessions.zip` | S&P Sessions |
| `SP-Album-Art-Studio.zip` | S&P Album Art Studio |
| `SP-Accounting.zip` | S&P Accounting |
| `SP-Suite.zip` | The manager (install once by hand) |

Keep the repo **public**. After replacing a zip, bump `version` in `suite.json` and commit both.
